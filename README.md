# Larion — демоверсия для GitHub Pages

Статическая демоверсия Larion для проверки дизайна и интерфейса.

Содержимое: каталог, карточка товара, конструктор, предзаказ, галерея, корзина и вымышленное оформление. Кабинет, PHP, конфиги, заказы, сертификаты покупателей, переписка и резервные копии исключены.

Добавьте товар, откройте корзину и нажмите «Заполнить пример заказа». Отметьте согласие и нажмите «Проверить оформление — демо». В корзине появится подтверждение с демонстрационным номером заказа. Чтобы проверить выбор пункта выдачи, введите хотя бы две буквы, выберите Демогород и вымышленный пункт. Тестовая доставка стоит 350 ₽, код DEMO500 имитирует вычет 500 ₽. Заказы, оплата, письма и отправления в демо отключены.

Поля покупателя хранятся в памяти вкладки, демокорзина — в отдельном пространстве браузера. Не вводите реальные данные. «Сбросить демо» очищает только демоданные.

Сайт размещается в корне репозитория GitHub Pages. Пути к файлам относительные. Файл .nojekyll отключает обработку Jekyll.
